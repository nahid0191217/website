How this demo admin works

This storefront is a static site, so the admin panel stores its data in your browser (localStorage) — orders, settings and subscribers live on this device only. For a real online store, the same screens would connect to a backend + database (e.g. Firebase, Supabase or your own server) so data is shared across devices and customers.
